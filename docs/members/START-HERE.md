# Start here

You just joined the UCR Drone Project. This page is the only thing you need
to read today. It takes about five minutes.

## What you're actually going to do

You and one partner will build a small quadcopter from loose parts — a
circuit board, four motors, a 3D-printed frame — and then fly it. Nobody
expects you to know how any of it works yet. That's the point of the
project.

Roughly how the year goes:

| When | What |
|---|---|
| Fall | Build a **microdrone** from a kit of parts. Solder it, test it, fly it. |
| Winter | Move up to a **faster brushless drone** with real flight-controller software. |
| Spring | Obstacle courses, practice races, and competing against other schools. |

## What you need to know coming in

Nothing. Seriously. If you've never soldered, never used CAD, and don't know
what a "flight controller" is, you are the exact person this project was
built for.

What helps: showing up consistently. You'll be paired with someone, and the
two of you own one drone together. If you disappear for three weeks, your
partner is stuck.

## What to bring

- A laptop (any OS) — you'll install Arduino IDE on it, we'll walk you through it
- Safety glasses if you have them; the club has spares if you don't
- Patience for the first solder joint. Everyone's first one is ugly.

## The one rule that matters

**Propellers come off before you test anything.**

A spinning propeller on a bench is how people get cut, and it's the single
most common way beginners get hurt in drone projects. Every test script we
use tells you whether props should be on or off. Believe it.

Everything else safety-related is in [safety.md](safety.md) — read it before
your first build session, not after.
