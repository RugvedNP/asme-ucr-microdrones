# Sources & Attribution

This file documents exactly where the code in `build1-flix/test-scripts/`
came from, so nobody has to guess what's original club code vs. what's
reused from an upstream project.

Only [`okalachev/flix`](https://github.com/okalachev/flix) was used as a
source. The club hasn't started Build 2 (ESP-FC) work yet, so nothing here
is sourced from [`rtlopez/esp-fc`](https://github.com/rtlopez/esp-fc) —
update this file once that work begins.

flix is vendored in this repo as a git submodule at
[`build1-flix/flix`](../build1-flix/flix), pinned to commit
[`7312aef`](https://github.com/okalachev/flix/commit/7312aeff325302dd554cd968b598203c47ebc815)
(2026-08-12). flix does not publish an explicit `LICENSE` file — treat it as
reference material for attribution purposes, not as a source to copy wholesale
or redistribute as club-owned code.

## Written for this club, not sourced from either repo

- The 45° tilt cutoff, 100Hz safety loop, ARM/STOP command handling, and ramp
  timing in `tethered_hover_demo.ino`. (flix's own `disarmTilt` is 120°, see
  [`flix/safety.ino:11`](https://github.com/okalachev/flix/blob/7312aeff325302dd554cd968b598203c47ebc815/flix/safety.ino#L11) —
  we used the master prompt's 45° instead, since this is a bench safety guard,
  not flix's real in-flight disarm threshold.)
- The SBUS frame sync/decode in `preflight_check.ino` — a standard public
  SBUS bit-unpacking scheme (11-bit channels packed across 22 bytes), not
  copied from flix or esp-fc. flix doesn't implement SBUS decoding in the
  files referenced above, and esp-fc's CRSF/receiver code was never opened.
- All PASS/FAIL/WARN/SKIP threshold logic, drift/level math, and overall test
  structure — driven by the Section 1/3/8 prompts in [`CLAUDE.md`](../CLAUDE.md),
  not by either upstream repo.
